# DSH AI Hub 设计基线

**产品类型：** 企业内部能力治理工作台
**设计方向：** 克制、清晰、数据密集、接近桌面生产力工具而非通用管理后台
**设计参数：** 差异度 4/10，动效 2/10，信息密度 7/10

## 设计原则

1. 第一屏直接呈现登录或管理工作台，不使用营销型 Hero、插画、渐变和装饰性光效。
2. 信息层级主要依赖字号、字重、间距和边界，不依赖大面积品牌色；页面标题不重复使用模板化眉题。
3. 页面区块保持平面化；总览只使用一条连续指标带，列表以开放式分隔线组织，不使用成排白色统计卡和卡片套卡片。
4. MCP、Skill、API Key 等必要术语保留英文，其余界面文案优先使用简洁中文。
5. 管理动作始终可追溯；危险操作使用红色并与常规操作分离。

| 强边界 | `#C6D0D7` | `--line-strong` |
| 深黑导航 | `#0B1218` | `--nav`，侧栏与登录页顶栏 |

## 字体与密度

- 字体：系统无衬线字体，中文优先 `PingFang SC`、`Microsoft YaHei`。
- 页面标题：27px / 700；移动端 21px。
- 区块标题：15px / 700；正文和表格：12-13px。
- 数字、工号、会话 ID 使用等宽或等宽数字。
- 间距以 4px 为基础，常用 8、12、16、24、32px。
- 字距固定为 0，不随视口缩放字号。

## 组件规则

### 导航

- 桌面端使用 236px 深黑侧栏，导航按“总览、能力与交付、访问与接入、审计与运行”分组。
- 当前项使用同色系抬升背景和 2px 左侧指示线，不使用发光或渐变。
- 820px 以下改为顶部横向导航，保留图标和文字，可水平滚动。

### 按钮与表单

- 常规控件圆角 6px；每页只保留一个视觉主操作。
- 图标使用 Lucide；纯图标按钮必须有 `aria-label` 和悬停说明。
- 输入框必须有可见标签；移动端控件高度至少 44px。
- 焦点环使用 3px 半透明主色，禁止仅靠边框颜色表示焦点。

### 表格与状态

- 表头 39px，行高约 46px；数据列使用等宽数字。
- 小屏仅允许表格容器内部横向滚动，页面本身不得横向溢出。
- 状态同时提供中文文字、边框和颜色，不以颜色作为唯一信息。

### 弹窗与抽屉

- 圆角不超过 8px，仅使用一档阴影。
- 支持点击遮罩、关闭按钮和 Escape 退出。
- 移动端弹窗贴近底部，表单操作按钮并排或等宽显示。

## 动效

- 仅保留 140ms 的颜色、边框和背景状态过渡。
- 不使用滚动入场、悬浮位移、缩放或装饰性循环动画。
- 加载图标除外；`prefers-reduced-motion` 下将动画降至近乎静止。

## 禁止项

- 紫蓝渐变、霓虹、光球、毛玻璃和大面积深色科技背景。
- 英文大写眉题、营销口号、功能说明型占位文案。
- 超大标题、过度圆角、卡片套卡片、随机阴影。
- 直接从 GitLab 获取 Skill 的入口；Skill 统一由平台上传并审批。
- 管理端手工创建网关 MCP/Tool 的主入口；MCP/Tool 由网关同步登记。

## 交付检查

- [ ] 375、768、1024、1440px 宽度无页面级横向滚动和文本重叠。
- [ ] 正文对比度至少 4.5:1，所有交互控件有可见焦点。
- [ ] 图标来自同一套 Lucide，不使用 Emoji 或手绘 SVG。
- [ ] 加载、空数据、失败和禁用状态均有明确反馈。
- [ ] 登录页和工作台第一屏清楚显示 DSH AI Hub 产品身份。
